05-01 예지보전 대상 선정과 성과 평가 실습
 ─────────────────────────────────────────────────────────

[실습 목표]
- 설비와 고장 유형별로 적절한 보전 전략을 선택한다.
- 재현율과 정밀도를 계산하고 의미를 해석한다.
- 리드타임을 고려해 모델의 실제 현장 활용 가능성을 판단한다.


================================================================
문제 1 — 어떤 보전 전략이 적절한가? 
================================================================

철강 공장에서 다음 세 가지 고장 유형을 검토하고 있습니다.

A. 열풍 송풍기 베어링 열화
- 고장 영향 : 큼
- 고장 빈도 : 연 4회
- 고장 전 전조 : 진동이 점진적으로 증가
- 현재 데이터 : 진동 1분 주기, 고장 이력 있음
- 대응시간 필요 : 10일

B. 원료 컨베이어 이물 끼임
- 고장 영향 : 큼
- 고장 빈도 : 연 2회
- 고장 전 전조 : 직전까지 특별한 변화 없음
- 현재 데이터 : 전류·속도 데이터 있음
- 대응시간 필요 : 1일

C. 예비 냉각수 펌프 씰 열화
- 고장 영향 : 작음
- 고장 빈도 : 연 1회
- 고장 전 전조 : 압력 저하가 나타남
- 현재 데이터 : 압력 데이터 있음
- 대응시간 필요 : 2일


각 대상에 가장 적절하다고 생각하는 보전 전략을 하나 고르세요.

선택지
- BM  : 사후보전
- TBM : 시간기준보전
- CBM : 상태기준보전
- PdM : 예지보전


A. 열풍 송풍기 베어링 열화

선택 :
→ PdM : 예지보전

이유 :
→ 고장 영향이 크고 정비를 위한 대응시간이 길게 필요하므로, 
  사전에 고장 시점을 예측하여 리드타임을 확보하는 것이 중요합니다.
→ 진동이 점진적으로 증가하는 뚜렷한 전조가 있고, 
  주기가 짧은 진동 데이터 및 고장 이력이 존재해 예측 모델을 구축하기에 적합합니다.

B. 원료 컨베이어 이물 끼임

선택 :
→ BM : 사후보전

이유 :
→ 돌발성 고장이므로 직전까지 변화가 없어 사전에 고장을 예측하는 예지보전은 불가능합니다.
→ 전류·속도 데이터를 통해 이물이 끼는 즉시 설비를 정지시키는 상태기준보전 알람이나 발생 
  즉시 조치하는 사후보전(BM)이 현실적입니다.

C. 예비 냉각수 펌프 씰 열화

선택 :
→ CBM : 상태기준보전

이유 :
→ 고장 영향이 작아 예지보전 모델 구축 비용 대비 효과가 낮으며 예비 설비가 존재해 즉각적인 위험이 적습니다.
→ 압력 저하라는 명확한 전조가 나타나고 관련 데이터가 있으므로, 
  압력이 특정 임계치 이하로 떨어졌을 때 알람을 띄우고 정비하는 상태기준보전이 가장 효율적입니다.

※ 설비 이름만 보고 고르지 말고,
   고장 영향 · 빈도 · 전조 · 측정 가능성 · 대응 가능성을 함께 보세요.


================================================================
문제 2 — 모델의 재현율과 정밀도 계산================================================================

A 설비에 예측 모델을 적용했습니다.

지난 1년간 실제 베어링 고장은 10건 발생했습니다.

모델 결과는 다음과 같습니다.

- 실제 고장 10건 중 사전 경보 성공 : 8건
- 놓친 고장                         : 2건

- 전체 경보                         : 20건
- 그중 실제 고장과 연결된 경보      : 8건
- 오탐                              : 12건


[1] 재현율을 계산하세요.

재현율
= 실제 고장 중 사전에 잡아낸 비율

계산 :
→ (사전 경보 성공 8건 / 실제 고장 10건) * 100
답 :
→ 80 %

[2] 정밀도를 계산하세요.

정밀도
= 발생한 경보 중 실제 이상이었던 비율

계산 :
→ (실제 고장과 연결된 경보 8건 / 전체 경보 20건) * 100
답 :
→ 40 %


[3] 현장 작업자가 더 직접적으로 체감하는 지표는
    재현율과 정밀도 중 무엇이라고 생각하나요?

선택 :
→ 정밀도
이유 :
→ 정밀도가 낮으면 오탐이 잦아 현장 작업자가 불필요한 점검을 반복하게 됩니다.
→ 이는 작업자의 피로도를 높이고 결국 시스템 자체에 대한 신뢰도를 떨어뜨리는 
  양치기 소년 효과를 낳기 때문에 현장 수용성을 결정짓는 핵심 지표가 됩니다.

================================================================
문제 3 — 고장을 잡았어도 현장에서 쓸 수 있을까?================================================================

모델이 사전에 잡아낸 8건의 고장에 대해
경보 시점부터 실제 고장까지 남은 시간은 다음과 같습니다.

12일, 14일, 11일, 9일, 13일, 4일, 15일, 8일

이 설비는
부품 준비, 정비 일정 조정, 실제 작업까지 최소 10일이 필요합니다.


[1] 실제로 현장에서 대응 가능한 경보는 몇 건인가요?

→ 5 건


[2] 모델은 고장을 맞혔지만,
    대응시간이 부족한 경보는 몇 건인가요?

→ 3 건


[3] 이 모델을 단순히
    “재현율이 높으므로 현장에 충분히 쓸 수 있다”
    라고 평가해도 될까요?

[ ] 그렇다
[v] 아니다

이유 :
→ 현장 적용을 위해서는 단순히 고장을 맞히는 것을 넘어,
  부품 준비 및 일정 조정을 위한 최소 리드타임을 벌어주는 것이 목적이기 때문입니다.
→ 예측 성공 건수 중 약 37.5%는 대응 시간이 부족하여, 
  사실상 사후보전과 다름없는 결과를 초래합니다.

================================================================
문제 4 — 최종 판단================================================================

A. 열풍 송풍기 베어링 열화에 대해 최종 의견을 작성하세요.


[1] 예지보전 적용 대상 자체로는 적절한가요?

[v] 적절함
[ ] 적절하지 않음
[ ] 추가 확인 필요


[2] 현재 모델을 그대로 현장에 적용해도 될까요?

[ ] 가능
[v] 개선 후 적용
[ ] 적용 어려움


[3] 가장 먼저 개선해야 할 항목을 하나 고르세요.

[v] 더 이른 전조를 잡을 수 있는 신호 추가
[ ] 경보 임계값 조정
[ ] 정비 대응 절차 단축
[ ] 고장 사례 추가 확보
[ ] 기타 : ______________________________


[4] 최종 의견을 2~3문장으로 작성하세요.

→ A 설비는 점진적 전조가 뚜렷하고 파급 효과가 커서 예지보전 대상으로 매우 적합합니다.
→ 그러나 현재 모델은 10일의 정비 리드타임을 보장하지 못하는 경우가 있고,
  정밀도가 낮아 잦은 오탐으로 현장 신뢰를 잃을 위험이 큽니다.
→ 따라서 더 조기에 이상을 감지할 수 있는 추가 신호 확보를 통해 리드타임을 늘리고,
  임계값 최적화로 오탐을 줄이는 개선 작업을 거친 후 현장에 도입해야 합니다.

실습 마무리
─────────────────────────────────────────────────────────

이번 실습에서 최종적으로 판단해야 하는 것은
“모델이 고장을 맞혔는가?”만이 아닙니다.

- 이 고장을 굳이 예측해야 하는가?
- 고장 전에 반복 가능한 전조가 있는가?
- 현재 데이터로 그 전조를 볼 수 있는가?
- 모델의 경보가 실제 정비 준비시간보다 충분히 빠른가?
- 경보가 너무 많아 현장에서 감당하기 어려운 수준은 아닌가?

위 질문을 함께 봐야 예지보전 모델의 실제 현장 가치를 판단할 수 있습니다.
