================================================================
실습 1 — 정비 이력에서 학습용 사건과 라벨 창 설계 (약 20~25분)
================================================================

[1] 학습 대상 사건 선별

정비이력 CSV에서 MTR01의 '베어링 고장'을 예측한다고 가정합니다.

고장수리 기록 중 실제 베어링 손상 사건에 해당하는 record_id를 적으세요.

→ R003, R007 등

점검 / 예방정비 / 개조 기록을 학습용 고장 사건에서 제외해야 하는 이유를
한 문장으로 작성하세요.

→ 실제 고장으로 이어지는 물리적인 열화 전조 패턴을 포함하고 있지 않아,
  모델이 정상이나 단순 유지보수 상태를 고장 전조로 잘못 학습할 수 있기 때문입니다.

[2] 사건 시각 결정

각 기록에는 recorded_time, time_type, detected_time이 있습니다.

R003의 학습용 사건 시각으로 어느 값을 사용하는 것이 더 적절한지 적으세요.

선택 시각 :
→ detected_time

이유 :
→ recorded_time은 행정 처리나 정비가 완료된 사후 시점일 가능성이 높으므로,
  모델이 실제 물리적 이상 상태를 정확한 시점에 학습하려면 실제 고장이 발생하거나 감지된 시간인 detected_time을 기준으로 삼아야 합니다.

[3] 센서 그래프 확인 — Python 사용

05-05_라벨설계_센서데이터.csv에서 다음 그래프를 그리세요.

- x축 : timestamp
- y축 : vibration_rms
- 선 그래프

그래프를 보고 작성하세요.

진동 패턴이 평소와 달라지기 시작하는 시점은
고장 시각보다 대략 몇 시간 전으로 보이나요?

→ 대략 72~96시간 전

고장 직전 24시간의 패턴은 그 이전 구간과 비교해 어떤가요?

→ 진동 폭이 매우 급격하게 증가하며 진동의 최대치가 불규칙하게 튀는 등,
  초기 결함 상태와 확연히 다른 극단적인 비선형 패턴을 보입니다.

[4] 라벨 창 결정

다음 조건을 사용합니다.

- 고장 직전 24시간은 이미 고장이 크게 진행된 구간으로 보고 학습에서 제외
- 너무 긴 창은 아직 신호가 없는 시점까지 1로 포함할 수 있음

다음 중 가장 적절한 라벨 1 구간을 선택하세요.

[ ] A. 고장 24시간 전 ~ 고장 시각
[v] B. 고장 96시간 전 ~ 고장 24시간 전
[ ] C. 고장 168시간 전 ~ 고장 시각

선택 이유 :
→ 고장 직전 24시간은 이미 손상이 심각해 예측의 의미가 적어 제외하고, 
  전조 증상이 뚜렷하게 발현되기 시작하는 96시간 전부터를 유효한 
  사전 경보 구간으로 모델에 학습시키는 것이 현장 활용에 가장 적합하기 때문입니다.

정상 0으로 둘 구간 :
→ 고장 96시간 이전의 모든 과거 정상 가동 구간

학습에서 제외할 구간 :
→ 고장 24시간 전 ~ 고장 시각,
  그리고 정비가 완료되어 설비가 완전히 안정화될 때까지의 구간

[5] 라벨 누수 확인

센서 CSV의 다음 컬럼 중 모델 입력 특징으로 사용하면 안 되는 컬럼을 찾으세요.

- vibration_rms
- bearing_temp
- motor_current
- load_pct
- run_state
- post_repair_grade
- hours_to_failure

누수 가능 컬럼 :
→ post_repair_grade, hours_to_failure

왜 라벨 누수인지 작성하세요.

→ hours_to_failure는 모델이 최종적으로 맞혀야 할 미래의 정답을 직접적으로 포함하고 있습니다.
→ post_repair_grade는 고장이 발생하고 조치가 완료된 미래 시점에 생성되는 사후 데이터이므로,
  실시간 예측 시점에서는 절대 알 수 없는 정보입니다.

================================================================
실습 2 — 한계를 분류하고 대응 방안 작성 (약 10~15분)
================================================================

05-05_라벨설계_한계사례.csv의 L1~L4를 읽고 아래 표를 채우세요.

한계 유형
- 관측 범위
- 학습 범위
- 사례 수
- 원리적 불가


case_id | 한계 유형 | 왜 제한되는가? | 우선 대응
--------|----------|---------------|----------------
L1      |     사례 수     
|특정 베어링의 고장 사례가 1~2건에 불과해 고장 패턴을 일반화하여 지도학습하기 어려움
|고장 데이터가 필요 없는 '정상 데이터 기반 이상 탐지' 모델 우선 적용
L2      |     학습 범위     
|과거 데이터에 겨울철이나 특정 고부하 운전 조건의 데이터가 누락되어, 해당 환경에서 오탐 발생 가능성 높음
|다양한 계절/운전 조건의 데이터를 추가 수집하여 재학습
L3      |     관측 범위     
|현재 설치된 센서의 샘플링 주파수가 낮아, 베어링 미세 결함에서 나오는 고주파 신호를 포착하지 못함
|고주파수 측정이 가능한 정밀 진동 가속도 센서로 교체 또는 추가 설치
L4      |     원리적 불가     
|낙뢰, 외부 이물질 유입 등 돌발성 사고는 고장 전조가 서서히 나타나지 않음
|예지보전 대신 즉각 정지 로직 적용 및 물리적 방호벽 설치 강화


[최종 한계 진술]

L1~L4 중 하나를 골라 다음 형식으로 작성하세요.

“현재는 모델 학습에 활용된 데이터가 특정 계절(예: 봄~여름)에 편중되어 있는 학습 범위의 한계 때문에 
 겨울철 저온 환경에서의 설비 상태 변화에 대한 정확한 전조 판단이 제한된다.
 따라서 향후 1년간의 사계절 가동 데이터를 추가로 확보하고 환경 변수(외기 온도 등)를 
 모델링에 반영하는 작업을(를) 우선적으로 보완하거나 대안으로 적용한다.”
